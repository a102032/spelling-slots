# Spelling Slots

A slot machine spelling game for Grade 2 smartboards.

## Put it online with GitHub Pages
1. Upload every file and the `icons` folder to a **public** repository (keep the folder structure).
2. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
3. After a minute or two, open `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.

## Install on a smartboard
Open the address in **Edge** or **Chrome** and use the install icon in the address bar
(or Edge ⋯ → Apps → Install this site as an app).
Open the app once while online so it saves a copy for offline use.

## Change lists, dates or the default mode
Edit the **TEACHER SETUP** section near the top of the `<script>` in `index.html`, then commit.
Boards pick up the change the next time they open the app while online.
